# Skills de Design, Arte e Ilustração

Biblioteca de skills de design para o Claude Code, com curadoria (selecionadas por qualidade e estrelas no GitHub, nov/2026).
Ficam em `.claude/skills/`, então o Claude Code carrega todas automaticamente ao abrir este repositório.
Use `/nome-da-skill` ou apenas descreva a tarefa e a skill certa é acionada.

> Cada pasta mantém a licença original (LICENSE / LICENSE.txt). Mídias de demonstração (vídeos, GIFs, galerias, arquivos > 1 MB) foram removidas para manter o repo leve; veja o repositório de origem para os exemplos visuais.
